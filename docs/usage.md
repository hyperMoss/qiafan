# 使用说明

[返回项目首页](../README.md)

## 阅读与导航

当前 Android 版本的三个一级入口为“关注”“通知”“随便看看”，默认进入关注页。侧边栏提供个人主页、搜索、浏览历史、收藏与设置。

- 关注页支持下拉刷新与自动分页。切换主标签或从详情返回时，恢复本次登录会话中已加载的动态、分页位置和滚动位置。双击当前“关注”入口可刷新。
- 消息流向下浏览时收起工具条，反向滚动或回到顶部时恢复。首次加载显示卡片骨架；刷新时保留已加载内容。
- 点击动态进入详情，点击头像、作者或正文提及进入用户主页。详情正文支持系统文本选择与复制。
- “随便看看”读取公开动态，顶部提供动态或话题搜索与本机最近搜索。可在设置中关闭该入口，关闭后停止公开动态请求。当前界面没有单独的热门话题子页。
- 搜索支持全站动态、用户和指定用户内搜索。浏览历史与最近搜索保存在本机，可清除。

用户主页显示头像、昵称、签名与动态。受保护用户的内容由服务端权限决定；“已申请”表示等待对方通过，不代表已关注或已获得内容访问权限。

## 动态操作

点击卡片右上角“更多”或长按卡片打开操作菜单，详情页另有直接操作入口。

- “喜欢”对应饭否的收藏，可收藏或取消收藏。
- “转发”打开预填原作者和原动态正文的编辑页，可添加自己的评论；“快转”使用饭否转发参数直接提交。
- 自己发布的动态才显示删除入口。二次确认并由服务端成功删除后，才从当前列表与会话缓存移除；失败时保留内容并显示原因。
- 转发链按作者分段展示，保留中间评论。原动态可取得时补充引用卡，同一张原图不重复展示。

## 发布、回复与私信

关注页右下角可发布最多 140 字的纯文本动态。回复会在正文前添加 `@原作者昵称 `，缺少昵称时使用账号 ID；前缀计入字数限制。转发草稿超长时完整保留，调整到字数限制内后才能发送。发送失败保留编辑内容并恢复操作。图片发布尚未接入。

评论通过动态上下文接口读取，只显示当前账号可见且带有对应回复关系的内容。接口返回空结果时，不补造评论。昵称前缀下的线上回复关系仍需验证，详见 [验证记录](verification.md)。

通知按提及、私信和关注请求展示。未读数量与列表分别读取，计数接口不作为列表内容。私信支持读取会话与发送文本；界面展示的是接口已返回的数据，不保证包含完整历史。

## 原图、分享与网页

点击动态中的图片查看原图，可保存该张原图到系统“图片/恰饭”。没有原图的动态不显示保存入口，不提供批量保存。

动态可生成便笺、极简或深色样式的分享图片，保留转发链及引用图片。

正文网页链接默认使用内置 WebView 打开，右上角“浏览器”可转到系统浏览器。内置网页保持 HTTPS 传输；HTTP 链接尝试升级 HTTPS，网站不支持时显示错误。外部浏览器保留原始链接地址。

## 登录与认证

输入饭否用户名或邮箱和密码登录。客户端参考 [nofan 的登录实现](https://github.com/fanfoujs/nofan/blob/main/source/nofan.ts)，使用其[公开的 Consumer Key/Secret](https://github.com/fanfoujs/nofan/blob/main/source/util.ts)通过 xAuth 换取 Access Token。公开应用凭据包含在安装包中，其有效性取决于饭否与 nofan 应用的当前状态。

密码仅用于这次 HTTPS 请求，不写入本地存储。Token 使用 Android Keystore 加密保存在设备上。退出登录会清除授权、会话缓存、浏览历史与本机最近搜索。旧版手动输入 Consumer Key 和 PIN 的会话需要重新登录。

饭否 [API 文档](https://github.com/FanfouAPI/FanFouAPIDoc/wiki/Apicategory)较旧，文档中的能力不代表当前服务一定可用。客户端仅通过 HTTPS 传输，按 nofan 的兼容方式使用 HTTP 地址计算 OAuth 签名，不会将密码或令牌通过明文 HTTP 发送。服务端错误按实际响应显示。

## 当前验证范围

Android 构建和单元测试通过不代表所有真实接口与设备行为均已验收。登录、发送、删除和图片保存等能力的历史验证及待验收项，分别记录在 [验证记录](verification.md) 中。iOS、鸿蒙和 Web 尚未接入这套饭否客户端。
